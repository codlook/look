LOOK Documentation

A scripting language built for the web. This page is the full language reference — syntax, types, routing, database and 247 built-in functions across 32 modules.

Install

The fastest way — the official image on Docker Hub (no compilation):

terminal
docker run -p 7400:7400 -v "$PWD/app:/app" codlook/look

Drop in ./app/index.lk, open http://localhost:7400/. For Linux server, Plesk and Windows installs see the install section on the home page. Editor support: the VS Code extension.

Your first index.lk

index.lk
// Note: LOOK has no statement-ending semicolons
route("GET", "/", fn($req) => response::json(["hello" => "world"]))

route("GET", "/hello/:name", function($req) {
    $name = request::param("name")
    return response::json(["message" => "Hello, " . $name])
})

Syntax basics

  • Variables are prefixed with $: $name = "Ada". Reading an undefined variable is an error (strict).
  • No semicolons. Statements end at the end of the line.
  • Comments: // line, # line, /* block */.
  • Output: print(...) and write(...) (parentheses required).
  • String concatenation uses the dot: "a" . "b" (+ is arithmetic).
Strict by design: an undefined variable is an error, type-strict == (1 == "1" → false), full 64-bit integer comparison. A value that can't be converted to a number doesn't silently become 0 in arithmetic — it throws.

Types & arrays

Primitive types: int (64-bit), float, string, bool, null, array, function. Integers are full 64-bit — phone numbers/IDs don't silently corrupt.

types.lk
// Indexed array
$colors = ["red", "green", "blue"]

// Assoc array (key => value)
$person = ["name" => "Ali", "age" => 30]
print($person["name"])         // Ali

// Nested
$data = ["users" => [["name" => "Ada"]]]

Type conversion: int(...), float(...), string(...). DB columns convert automatically; you only need it for user input: int(request::get("id")).

Watch out: + is arithmetic, not concatenation. Use . to join text. A non-numeric operand in arithmetic (null, array, non-numeric string) throws — it doesn't silently fall back to 0.

Strings & interpolation

string.lk
$name = "Ada"
// Double quotes — interpolation on, {$x} auto HTML-escaped
print("Hello {$name}!")          // Hello Ada!
print("Square: {math::pow(4,2)}")  // expressions work too

// Raw (unescaped) interpolation: {!$x}
// Backtick — raw string, NO escaping/interpolation
$sql = `SELECT * FROM users
WHERE active = 1`

In a double-quoted string, {$variable} and {expression} are interpolated and auto HTML-escaped (XSS protection). For unescaped output use {!$x}. A backtick string (`...`) is raw — ideal for multi-line SQL.

Control flow

No semicolons. The for loop is space-separated, and switch is Go-style (no break needed).
akis.lk
// if / elseif / else
if ($score >= 90) { print("A") }
elseif ($score >= 80) { print("B") }
else { print("C") }

// for — space-separated (NO ;), $i++ increment
for ($i = 0 $i < 10 $i++) {
    print("{$i} ")
}

// foreach — arrays and assoc
foreach ($colors as $color) { print($color) }
foreach ($person as $key => $value) { }

// switch — Go-style: NO break, each case exits automatically
switch ($status) {
    case "active":
        print("running")
    case "pending", "paused":   // multiple with commas
        print("stopped")
    default:
        print("unknown")
}

// while — break / continue
while ($i < 5) { $i++ }

Functions & closures

fn.lk
// Classic function (with default parameters)
function greet($name, $greeting = "Hello") {
    return $greeting . ", " . $name
}

// Short lambda — fn + arrow, implicit return
$square = fn($x) => $x * $x

// Closure — EXPLICIT capture with use() (no hidden globals)
$factor = 3
$multiply = function($x) use ($factor) {
    return $x * $factor
}

Closures capture their dependencies explicitly with use (...) — there are no hidden globals. For a connection shared across routes, use app::set / app::get.

Error handling

error.lk
try {
    if ($x < 0) {
        throw error::new("invalid", "negative value", 400)
    }
} catch ($e) {
    log::error(error::message($e))
    if (error::is($e, "invalid")) { }
}

Throw a plain string or a structured error::new($type, $message [, $code]). Inspect it with error::is / code / message. error:: is always available (no use needed). Every error also reports the File and Line where it occurred.

Routing

Routing is built into the language — REST, WebSocket and SSE all use the same route(). URL parameters (:id) are parsed automatically.

routes.lk
route("GET",  "/products",      $list)
route("GET",  "/products/:id",  $show)
route("POST", "/products",      $create)
route("WS",   "/chat",          $ws)
route("SSE",  "/events",        $sse)

Group routes under a shared prefix (and middleware) with route::group("/api", [$auth], fn).

request:: / response::

Database

MySQL, MariaDB, PostgreSQL and SQLite — the same db:: API, different DSN. Queries are parameterized (?) — injection-safe.

db.lk
$c = db::connect("mysql://user:pass@127.0.0.1/dbname")
$rows = db::query($c, "SELECT * FROM users WHERE id = ?", [$id])
db::exec($c, "INSERT INTO users(name) VALUES(?)", [$name])
// Transactions: db::begin / commit / rollback · db::transaction($c, fn)

WebSocket & SSE

realtime.lk
// WebSocket — ws::on / send / broadcast / clients
route("WS", "/chat", function($conn) {
    ws::on($conn, "message", function($m) {
        ws::broadcast($m)
    })
})

// SSE — sse::send / on / close · periodic: timer::every
route("SSE", "/prices", function($conn) {
    sse::send($conn, json::encode($tick))
})

Design decisions

  • Routing built into the language — no framework to install.
  • No global variables — closures capture explicitly with use(); shared state via app::.
  • No OOP — deliberate. struct only groups data (no inheritance/methods).
  • No mixed arrays — an array is either indexed or assoc.
  • No semicolons — statements end at the end of the line.
  • Strict defaults — undefined variable is an error, type-strict ==, full 64-bit integers.
